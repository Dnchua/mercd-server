## 写作约定

文档使用自行撰写的技术解释和数学表达。页面关系、协议 schema 与字段表保留细节，不复制游戏原始素材；读取位置保留类型名或服务端符号。

示例不使用真实个人信息：个人姓名、账号值、口令、令牌、密钥字面值、设备标识、局域网地址、邮箱电话和绝对路径一律不出现。协议的 user_id、user_name、token、sk 等字段名保留，因为它们是契约的一部分；文中的通用占位符不代表真实数据。

已验证结论与推导结论分开标注。迁移数量不写成固定值，因为它随版本增长。

## 时间与验证边界

页面覆盖状态及战斗差分基于历史分析快照，文中标出了对应时点。写文档不等于重新验证客户端：某个样例或分支通过，不能扩展成整个游戏已验证。未获得官方真值的数值标为重建值或待验证。

数据来源说明保留来源性质——重建加工不改变第三方内容的权属。
