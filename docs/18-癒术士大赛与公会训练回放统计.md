### 0.1 解密目录重建

M5/M8 文档引用的只读解密目录 `cn-mercd-backend/artifacts/mlk-capture-201711/decrypted/` 已不在本机。M10 用原始 `mlk虚拟服务器/{1,2,3,default}.mlk` **只读**重建到仓库外的临时目录（不入库）：

| 环节 | 规则 |
|---|---|
| 容器格式 | `u32 记录数`，每条记录 `u16 键长 + 键("METHOD URL") + u32 响应数 + N×(u32 长度 + 原始 HTTP 响应)`；`default.mlk` 记录数头大于实际条数，按文件末尾截止 |
| 账号通道 | 响应 `chunked`；帧头 `00 64 + MD5` 为明文，载荷 `XOR 0x71 → zlib → AES-CBC(MD5("momocahehe"), MD5("c368c368"))`；marker `1` 后 32 字节即 S0 |
| 游戏通道 | `GameCipher(S0, S1)`（`server/internal/cn35protocol`）；S1 为客户端未播种 `lrand48()` 序列的首 32 次取模 62 字符（`qhhN…`），与 `cn35protocol.S1Charset` 一致 |
| 结果 | 游戏明文 9027 条、失败 12 条，与 `cn-mercd-backend/server/testdata/mlk-live/all/contract.json` 的计数完全一致 |

## 1. 社区资料摘要【公告/社区】

- **癒术士大赛**（国服独有，2015 年起按「届」举办，录播时为第 32/33 届）：入口在主人公等级圆圈 → 主人公的日常 → 癒术士大赛；每届第一周为**排位赛**，其余为**分段赛**（SS/S/A/B 四级，每周二 21:00 结算）；每日 3 次免费挑战（第二届起），取消了极难以上难度；战斗方式是「用同伴队伍挑战对方防御魔宠，与公会战形式基本相同」；奖励主体是**天赋树叶**（排行奖励为主）与**增幅药水**（战胜掉落），药水只在大赛中给防御魔宠「增幅」。
- **公会训练**：v2.0.0（2015-04）以「纯测试」名义上线的「未来公会战新玩法测试区」；页面文案仍写着「为了提供更好的公会战斗感受……对该战斗玩法进行提前测试」。玩法是**攻守两套同伴编队的自动对战**（同伴打同伴，`Quest/AutoQuest`），v2.1.0 曾下调治疗职业效果并把天赋并入训练数值。
- 两个玩法的「天赋树叶」都服务于**潜能/天赋**养成；本项目已把潜能、天赋、主角光环列入不复原板块，因此叶子奖励需要替换（见 §4）。

## 2. 癒术士大赛契约

### 2.1 页面链路【客户端源码】

```text
主人公的日常 function_portal_list(name=ladder) → LadderMainPage(/ladders/show_ladder_info + /users/preset_data/)
  ├ 开始挑战 → LadderChallenger(/ladders/get_candidates) → 行 fight_btn → LadderSelect(message.addition=user_id=…)
  │     └ LadderQuestSelectParts.StartClick → name=LadderQuest&base=Quest/Quest&mode=ladder&difficulty_id=…&user_id=…&party_id=…
  │           → GET /ladders/ladder_quest_execute.json → ap_use_url(/ladders/lc_used) → result_url(/ladders/attack)
  ├ 防御设定 → LadderDefenceConfig(/ladders/monsters)：LadderDeckButtonsListComponent → /ladders/set_deck、/ladders/remove_from_deck
  ├ 规则说明 → ShowRule(rule_title/rule_info)
  ├ 排行榜 → LadderRankingList(/ladders/show_rank)：领取按钮 url=ladders/fetch_rewards
  └ 魔宠增幅 → LadderMonsterGrow(/ladders/monster_grow_index)：/ladders/monster_grow_upgrade、/ladders/monster_grow_upgrade_reset
```

- `LadderMainPage` 固定读 6 个 `btn_list` 元素；`disable_key=ladder_deck_empty` 时弹 `disable_body` 并跳 `disable_page`。
- `has_ladder_rewards` 为字符串比较 `"true"`，控制主页 New 角标。
- `LadderDeckListParts` 读缓存 `ladder_deck_data.powerup_rate`（5 个浮点），按格显示「x1.0…x1.8」并按此倍率合计体力/攻击。
- `LadderQuestSelectParts` 读 `consts.ladder_difficulty`（`normal/hard/very_hard/impossable` 文案 + `impossible_lock`）与缓存 `ladder_condition`（7 键武器倍率）。
- `Quest.cs`：`isLadderBattle` 时 boss 的 `PowerUpHpRate/PowerUpAtRate` **加上** `monster_grow_hp_powerup_rate/monster_grow_at_powerup_rate`；助战/救援关闭；结算屏读 `ladder_score`（>0 显示）与 `ladder_score_text`。
- `MonsterGrow.cs`：列表行 `rate`（显示为 %）、`max_rate`、`price`（每级药水数）、`step`（每级增量）、`remain_count`、`url`（客户端拼 `count`）；顶部 `item_count`；重置调 `reset_url`。

## 3. 公会训练契约

### 3.1 页面链路【客户端源码】

```text
function_portal_list(name=rob_battle) → RobBattleMainPage
  requireData: /users/preset_data/、/user_rob_decks?party_type=def、/rob_battles/show_rob_battles_info（rob_battle_record + rob_battle_enter）
  ├ 入场按钮 ×3（RobBattleMainEnterParts）：can_buy → /rob_battles/buy_rob_ticket?ticket_id=N；can_enter → 校验防守 2 队满员 → RobBattleChallenger
  ├ 防守页签（RobBattleUserDeckListParts party_type=def）→ RobBattleUnits 选择 → /user_rob_decks/on|off?party_type&party_id&party_index&unit_id
  └ 战绩页签 rob_battle_record（fight_btn「复仇」→ RobBattleQuestSelect）
RobBattleChallenger(/rob_battles/get_candidates) → RobBattleQuestSelect
  requireData.rob_battle_ready 被候选行 message 覆盖为 /rob_battles/battle_ready?user_id=…
  └ StartClick：攻击 2 队满员 → name=RobBattleQuest&base=Quest/AutoQuest&mode=rob_battle + addition(&user_id=…)
        → GET /rob_battles/rob_battle_quest_execute.json → ap_use_url → result_url / lose_url
```

- `RobBattleUserDeckButtonsListComponent` 按 `consts.rob_battle_career_limit`（`{"7":2}`：治疗职业最多 2 人）在客户端限人数。
- `RobBattleQuestSelectParts`：`score_mode=true` 显示 `reward` 文案，否则读 `rob_battle_condition` 显示武器倍率。
- `AutoQuestExecuteDocument` 解析键：`quest`、`units`（列表）、`enemy`（列表）、`monsters`、`main_character`、`appear_table`、`help_table`、`timezone_table`、`boss_appear_table`、`asset_names`、`battle_log`、`clear_count`。
- `AutoQuest`：全部 `enemy` 倒下或我方到达旗帜即胜；`time_limit` 到时或我方全灭即败；`flag_image_name`/`enemy_flag_image_name` 缺省 `common/player_flag`/`common/enemy_flag`（必须在 `asset_names` 里）；敌方魔宠按 `monster_uuid` 在**本人** `user_monsters` 缓存里找，找不到即不可召唤。
- `SWFAutoQuestClear`：读 `rob_battle_score`（>0 显示）与 `rob_battle_score_text`；`SWFAutoQuestLose` 仅在有 `lose_url` 时上报。

- 积分起始值、分差系数、防守方扣分无样本；战绩行结构只有 app_conf 行配置。

## 4. 重建决策【重建值】

| 项 | 决策 |
|---|---|
| 对手来源 | 本地其他真实账号（设置过防御魔宠 / 防守编队满员）优先，不足用**确定性 NPC 参赛者**补足（癒术士大赛 20 名、公会训练 10 名）；NPC 不入排行榜 |
| 赛季 | 以 2017-10-31（周二）21:00 UTC+8 为锚点，每 28 天一届；第 1 周排位赛、其余分段赛；届末积分清零 |
| 分段 | 本地无全服人数，按积分划档：B <300、A 300–599、S 600–999、SS ≥1000 |
| 积分 | 战胜 `round(clamp(20 + (对手-自己)/10, 5, 60) × 难度倍率)`；真实对手防守失败扣 `⌊增益/2⌋`（不低于 0） |
| 困难难度 | 系数 4、间隔 80 秒（推断，介于普通与极难之间） |
| 掉落 | 胜利发放：增幅药水 3–8 个（三种随机）、公会建设素材 50、金币 30；**去掉潜能叶子掉落** |
| 周结算奖励 | 按上周结束时分段发放到排行领取：SS 金币 8000 + 徽章 40、S 4000 + 30、A 2500 + 12、B 1000 + 8；原文叶子奖励按 普通 1/稀有 3/传说 10 徽章 的比例折算（仅本周有出战记录才结算） |
| 增幅价格 | 每级 50 药水；同页每多一个已升级属性，价格 +25（魔阻） |
| 公会训练入场券 | 每日依次购买：免费 → 50000 金币 → 100000 金币；每张券把 `rc` 补满到 5，`rc>0` 时不可再购 |
| 公会训练积分 | 起始 1000；战胜 `clamp(30 + (对手-自己)/20, 10, 60)`；真实对手防守失败扣 `⌊增益/2⌋` 并写入其战绩（可复仇一次） |
| 次数重置 | 两个玩法都按 UTC+8 04:00 切日（与星盘/面包店一致） |
| 有意差异 | 癒术士大赛额外下发 `lose_url=/ladders/lose`、公会训练使用重建端点 `/rob_battles/rc_used`、`/rob_battles/attack`、`/rob_battles/lose`；敌方同伴不下发 `monster_uuid`（防止误命中本人魔宠缓存） |
