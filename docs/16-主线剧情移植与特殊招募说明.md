## 1. 剧情版 APK 只读拆解与主线完整度评估

### 1.1 只读拆解结论

对玩家提供的剧情版安装包（`<剧情版APK路径>`，仓库外只读读取、不入库）与项目基线（`inputs/apk/国服-3.5.0.apk`、`client/decoded/`、`inputs/files/`）进行只读比对，结论如下（**原作观测 / 文件实测**）：

1. **客户端逻辑与原包一致**：安装包内 `Assembly-CSharp.dll` 大小为 `2,849,280` 字节，与原版国服 `CN3.5.0` APK 完全一致，未对原游戏 DLL 业务逻辑做篡改，不存在反编译私改逻辑冲突。
2. **随包资源包闭合情况**：安装包内含 `17,267` 个 `.Android.unity3d` 资源包，与本仓库 `client/decoded/assets/unity/` 及 `inputs/files/` 本地资源全集完全一致；全包 `4,008` 篇简体中文剧本（`StoryYamlData_1` ~ `StoryYamlData_4349`）在叠加资源清单下 **4,008 / 4,008（100%）通过资源依赖闭合检查**。
3. **仅依赖基线短期清单的资源覆盖**：仅靠服务端基础资源清单（`server/assets/cn350/serve_asset_info_android4_v2_short.txt`）时，仅 **29 / 533** 话主线通过校验；装配远端叠加目录（`-remote-assets` 指向 `inputs/files` 或等价叠加目录）后，**533 / 533** 话主线立绘、背景与 BGM 全部通过 `story.go` 启动资源闭环检查。
4. **结构差异与可移植性**：**可以安全移植回本项目服务端**，但不能直接裸拷安装包内离线剧本 JSON：
   - 安装包原脚本将剧情 `id` 重排为 `1..4008`，且部分章节标题保留了日文片假名；
   - 离线播放器裁剪了 `speaker`、`active`、`display_name`、`key`、`type:"navi"` 等场景字段，直接下发会导致在线客户端 `StoryPage` 对话人物/高光/旁白异常。
